# 🏃‍♂ Race Event Data Analysis (EDA with Pandas & Seaborn)

This project performs an *Exploratory Data Analysis (EDA)* on a *Race Event dataset* using *Python, Pandas, and Seaborn*.  
It explores trends in *participant performance, **age, **gender, and **race distance* through data cleaning, descriptive statistics, and visualization.

---

## 🧰 Tools & Libraries Used
- 🐍 *Python*
- 🐼 *Pandas*
- 🎨 *Seaborn*
- 📓 *Jupyter Notebook*

---

## 📘 Dataset Information
The dataset contains information about race participants and their event performance.

| Column | Description |
|--------|--------------|
| athlete_id | Unique participant ID |
| race_day | Race date |
| athlete_gender | Male / Female |
| athlete_age | Age of participant |
| race_distance | Distance in kilometers and Miles |
| athlete_performance | Completion time in minutes |
| race_season | Race event held on different seasons |
| avg_speed | Average speed of participants |
